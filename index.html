Acoustic Annotator

ブラウザ音響分析 & Praat TextGrid エディタ
開発のきっかけ // 音響音声学で使うPraatをもっと手軽に、パソコンがなくても直接スマホやタブレットから録音して分析できるようにしたいと思って作りました。
  • ブラウザ上での音声録音と、無音区間の自動検出・区間分割
  • 基本周波数（F0）のピッチ推定とLPCフォルマント（F1〜F3）の抽出
  • F1-F2母音四辺形散布図のリアルタイム描画とCSV書き出し
  • Praat TextGrid形式の読み込み・書き出しに対応
  • 音声データを外部に送信せず、すべての解析をブラウザ内で完結

[ 02 / PHONETICS & TRANSCRIPTION ]

IPA Editor

国際音声字母エディタ & 声調記号入力
開発のきっかけ // 記述言語学や音声学で扱うIPA（国際音声字母）の特殊記号を、パソコンだけでなくスマホからでも手軽に入力したくて作りました。
  • 肺臓気流子音・非肺臓気流子音・母音・補助記号など、IPAの各記号に対応
  • 数字キー（1〜5）の入力から趙元任の声調バー（Chao Tone Letters）を合字変換
  • ベース文字の並びを崩さずにダイアクリティカルマーク（結合記号）を付与
  • ボタン一つでクリップボードへコピー（日本語・英語の表示切替に対応）

Syntax Tree Editor

構文木エディタ & 統語階層可視化
開発のきっかけ // 統語論や意味論で扱う構文木を、授業のノートや板書、レポート作成時にパソコン上ですばやく組み立てたくて作りました。
  • ブラケット記法（かっこ表記）から構文木をリアルタイムに自動描画
  • TP/DP体系（生成文法）とS/NP体系（伝統文法）をボタン一つで切り替え
  • 構成素の移動を表す矢印描画と、下位構造の三角形省略記法
  • LaTeX（forest / qtree）形式のコード生成、SVG・PNG画像としての保存

Phonological Rule Editor

音韻規則・音変化エディタ & KaTeX出力
開発のきっかけ // 歴史言語学や音韻論で出てくる音韻規則を、パソコン上できれいに表示できるようにしたくて開発しました。

  • KaTeX形式の数式プレビュー表示とLaTeXコードの生成
  • レポートやスライドにそのまま貼れるSVG・高解像度PNG画像の書き出し
